# Lsearch — TUI（终端界面）使用手册

面向麒麟（Kylin V10）等桌面的 Everything 风格文件名搜索工具，`lsearch-tui`
是其终端交互界面。本文教你从启动、查找、打开到排障的全部用法。

---

## 1. 这是什么

`lsearch-tui` 是 Lsearch 的**文本终端界面（TUI）**。它连接常驻守护进程 `lsearchd`
（持有内存索引 + SQLite 持久化 + inotify 实时增量），实现**输入即搜**——每敲一个字符
结果即时刷新，体验对齐 Windows 的 Everything，但只跑在终端里（适合 SSH、无图形环境、
轻量运维场景）。

> 关系：`lsearchd`（守护进程）负责建索引和搜索；`lsearch`（命令行）和
> `lsearch-tui`（交互界面）都是它的前端。TUI 只是"画界面"，真正的索引在守护进程里。

## 2. 运行前提

- **真实终端**：本地终端、SSH、tmux/screen 均可；纯管道/重定向（无 TTY）无法运行。
- **UTF-8 环境**：终端 locale 建议 `C.UTF-8` / `zh_CN.UTF-8`，中文文件名/输入正常显示。
- **守护进程可自动拉起**：连接不上 `lsearchd` 时 TUI 会自动把它拉起并建索引，一般无需手动启动。

## 3. 启动

```bash
lsearch-tui            # 直接进入界面（守护进程不在会自动拉起）
# 或并行场景：先手动启动守护进程，再进 TUI
lsearchd --foreground &
lsearch-tui
```

进入后顶部会先出现 `Search:` 与状态栏；若索引刚建好，几秒内即可搜索。

## 4. 界面布局

```
┌─────────────────────────────────────────────┐
│ Search: report                     ← 搜索框   │
├─────────────────────────────────────────────┤
│ [目录] AnnualReport.txt       ← 结果列表      │
│ [文件] reports/                              │
│ [文件] Report.docx                          │
│                        …                      │
├─────────────────────────────────────────────┤
│ 索引 files=12345 dirs=6789 size=1.2 GB | 匹配 8 │ ← 状态栏
│ | Enter 打开  F5 重建  Esc 清空  Ctrl+Q 退出    │
└─────────────────────────────────────────────┘
```

- **第 1 行 搜索框**：`Search:` 后即输入区，光标定位在你敲的字。
- **中间 结果列表**：
  - 每行左侧有**类型标签**：`[目录]`（绿色）/ `[文件]`，一眼区分文件夹与文件；
  - 接着是**文件名**（命中的子串**加亮**）+ 右侧灰色完整路径；
  - **反白（高亮）行** = 当前选中项。
- **最后 1 行 状态栏**：
  - 左侧：**索引统计**（`索引：N 个文件 · M 个目录 · 共 X`，每 3 秒刷新）；
  - 中间：`匹配 N`（N 为当前命中条数，最多返回 2000，超限显示 `N+`）；
  - 右侧：快捷键提示。

## 5. 快捷键一览

| 按键 | 功能 |
|---|---|
| `字符` | 输入/追加到搜索词（支持中文等 UTF-8） |
| `Backspace` | 删除最后一个字符（正确处理多字节/中文） |
| `↑` / `↓` | 上/下移动选中行（自动滚动） |
| `PgUp` / `PgDn` | 上/下翻一页 |
| `Home` / `End` | 跳到第一项 / 最后一项 |
| `Enter` | **打开**选中项（`xdg-open`：文件用默认程序、目录打开文件管理器） |
| `F5` | **重建索引**（全量重扫，状态栏提示"已触发重建…"） |
| `Esc` | **清空**搜索词 |
| `Ctrl+Q` / `Ctrl+C` | **退出** TUI（进程正常回收线程后退出） |
| （窗口变化） | 自动重排（`KEY_RESIZE`） |

> 说明：`Ctrl+Q` 与 `Ctrl+C` 都能退出 —— 程序用了 `raw` 终端模式，把 `^C/^Q`
> 作为按键接收，从而优雅退出（而不是被信号直接杀掉）。

## 6. 搜索：语法与规则

- **实时即输即搜**：输入即刻出结果（约 100ms 防抖），无需回车。
- **大小写不敏感**：`report` = `REPORT` = `ReporT`。
- **匹配范围**：只按**最终文件/文件夹名（basename）**匹配——名字里含关键词才出结果；
  完整路径**不参与命中**（例如搜 `code` 不会因为路径是 `/home/code/xxx` 而整目录刷出来）。
- **通配符**：输入含 `*` 或 `?` 时按通配符匹配：
  - `*.pdf` → 所有 PDF 文件；
  - `2025*report` → 以 2025 开头、含 report 的名字。
- **空输入**：清空后不显示全部结果（避免刷屏），提示"输入关键词开始搜索"。

示例：
| 输入 | 含义 |
|---|---|
| `rpt` | 名字含 `rpt`（子串，如 `report`、`Corrupt`） |
| `*.jpg` | 名字匹配 `*.jpg` |
| `2025?report` | `2025Xreport`（`?` 匹配单个字符） |
| `code` | 只命中名字含 `code` 的文件/文件夹（路径含的不算） |

## 7. 打开与定位文件

- **`Enter` 打开**：系统默认程序打开文件；若是目录，则打开文件管理器。
  - 底层调用 `xdg-open`，麒麟桌面一般已安装。
- 想"打开所在目录再处理"？可在文件管理器里定位（或用 CLI `lsearch` 拿到路径后自行操作）。

## 8. 索引管理

- **`F5` 重建索引**：全量重扫配置的根路径，适用于"守护进程中新增/删除了大量文件"、
  "配置改了 `paths`"、或想清掉脏数据时。
- **实时性**：守护进程用 inotify 监听，平时新建/删除文件**无需手动重建**，约 1 秒内自动反映到搜索。
- **索引统计**：状态栏左侧即索引规模（`files`=文件数、`dirs`=目录数、`size`=总大小）。
- 需要改索引范围/排除项？编辑配置文件 `~/.config/lsearch/lsearch.conf`（参见 README），
  或用 `lsearchd --add-path /path` / `--remove-path /path`。

## 9. 退出

- `Ctrl+Q` 或 `Ctrl+C`。程序会回收后台线程并恢复终端（`endwin`），不留残影、不留进程。
- 退出 TUI **不影响**守护进程：`lsearchd` 继续在后台跑，索引和 inotify 保持可用，
  下次进 TUI 秒开。

## 10. 排障 FAQ

**Q: 打开后一直停在"无法连接守护进程"?**
所在 `lsearchd` 没起或起失败。先手动前台起一次看日志：
```bash
lsearchd --foreground
```
若提示 `inotify 监控 … 个目录` 且 `ready on socket` 即正常；否则看错误信息。

**Q: 新建/删除的文件没在结果里更新？**
守护进程在跑才实时更新；若守护进程**停机期间**有改动，进来后**按 F5** 全量重建一次补上。
另外目录极多时 inotify 可能有上限（见下）。

**Q: 大量目录时提示 inotify 已满？**
守护进程会打印：
```
inotify watch 已满，增量监控不完整。可调高 /proc/sys/fs/inotify/max_user_watches。
```
root 下执行调高即可，然后重启 `lsearchd`：
```bash
sysctl fs.inotify.max_user_watches=524288
```

**Q: 中文显示/输入乱码？**
确认终端 locale 是 UTF-8：`echo $LANG`（应含 `UTF-8`）；SSH 客户端也建议 UTF-8。

**Q: 想脚本里用搜索/排序/计数？**
用命令行前端更合适：
```bash
lsearch *.pdf
lsearch --sort size -S 'log'
lsearch --count report
lsearch -d 'bin'
```
TUI 面向人机交互，脚本请走 `lsearch`。

**Q: 卡死/终端花了？**
可强制退出再 `reset` 复位终端；TUI 本身在窗口尺寸变化时会自动重排。
